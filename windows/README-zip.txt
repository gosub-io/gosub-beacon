Gosub Beacon Preview for Windows (x64)

Unzip this folder anywhere and run GosubBeacon.exe. Nothing else needs to be installed.

This preview is not signed. The first time you start it, Windows SmartScreen says
"Windows protected your PC". Click "More info", then "Run anyway".

Your profile is kept in %APPDATA%\gosub-beacon. Its log, beacon.log, is in the profile's
folder under profiles\; attach it when you report a problem.
