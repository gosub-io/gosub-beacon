Gosub Beacon 0.1.1-preview.1 is the first preview of Beacon on Linux, macOS, Windows and
Android. Beacon is the browser built around the [Gosub engine](https://github.com/gosub-io/gosub-engine),
and exists to test that engine in a real application. Basic browsing works; it is not a
daily driver.

Every file name carries the Beacon build number, the Beacon commit and the engine commit:
`GosubBeacon-<version>-<build>-<commit>-engine-<engine>`.

## Downloads

| Platform | File name ends in | Needs |
| --- | --- | --- |
| Linux | `-x86_64.flatpak` | flatpak, x86_64, a running Secret Service (GNOME Keyring, KWallet) |
| macOS | `.dmg` | macOS 13 or newer, Apple silicon or Intel |
| Windows | `-win-x64.zip` | 64-bit Windows; nothing else to install |
| Android | `-arm64-v8a.apk`, `-armeabi-v7a.apk` | Android 10 or newer, Vulkan 1.1; armeabi-v7a only for 32-bit devices |

Check a download against `SHA256SUMS`:

```bash
sha256sum --check --ignore-missing SHA256SUMS      # Linux
shasum -a 256 --check --ignore-missing SHA256SUMS  # macOS
```

```powershell
Get-FileHash .\GosubBeacon-*-win-x64.zip           # Windows; compare with SHA256SUMS
```

### Installing

- **Linux:** `flatpak install --user GosubBeacon-*.flatpak`, then `flatpak run io.gosub.beacon`.
  It fetches the GNOME 50 runtime from Flathub if that is not installed yet. Local files (`file://`) are off;
  `flatpak override --user --filesystem=host:ro io.gosub.beacon` turns them on.
- **macOS:** open the DMG and drag Beacon to Applications. The app is signed and notarized.
  The profile's key is kept in the keychain; macOS may ask once to allow that.
- **Windows:** unzip anywhere and run `GosubBeacon.exe`. The zip is not signed, so
  SmartScreen warns on the first start: "More info", then "Run anyway".
- **Android:** install the APK (allow installs from your browser or file manager). A newer
  preview installs over this one and keeps your profile.

## What is not there

- **No JavaScript.** Pages that need it to show their content stay empty or partial.
- **No search.** The address bar takes URLs only (GOS-49).
- **No auto-update.** New builds appear on the [Releases page](https://github.com/gosub-io/gosub-beacon/releases);
  watch the repository for "Releases only" to hear about them. Install the new build over
  the old one; the flatpak bundle too, since there is no flatpak repository behind it.
- **No HSTS** (GOS-58) and **no IDN spoof protection** (GOS-53): a look-alike domain in
  another script is shown as it is, not as punycode.
- **No certificate exceptions** (GOS-55): a site with a bad certificate cannot be opened.
- **No process isolation.** Every platform runs pages in Beacon's own process. Isolation is
  Linux-only and off in this preview; it is planned for a later one
  ([docs/isolation.md](https://github.com/gosub-io/gosub-beacon/blob/v0.1.1-preview.1/docs/isolation.md)).
- gopher, finger and gemini are switched off.

## Known issues

- **Android, Mali GPUs:** Beacon cannot draw pages on a device with an Arm Mali GPU; the
  page stays blank and Beacon says so. Waiting on a fix in Vello
  ([KI-001](https://github.com/gosub-io/gosub-beacon/blob/v0.1.1-preview.1/docs/known-issues.md#ki-001-mali-gpus-lose-the-vulkan-device), GOS-162).
- **Cookies:** after a failed load, the cookies of that zone can be lost (GOS-129).
- **Navigation:** clicking a new link while a page is still loading can show an error for
  the old one, or the old page over the new one (GOS-128).
- **Downloads:** after a download the tab's address shows the downloaded file's URL
  (GOS-234).
- **Linux:** the flatpak is x86_64 only. Without a Secret Service the profile cannot be
  encrypted and Beacon stops with an error.
- **Windows:** SmartScreen warns on the first start (see above).

The full list per platform is in [docs/known-issues.md](https://github.com/gosub-io/gosub-beacon/blob/v0.1.1-preview.1/docs/known-issues.md).
Report problems at [github.com/gosub-io/gosub-beacon/issues](https://github.com/gosub-io/gosub-beacon/issues),
with the name of the file you installed.
